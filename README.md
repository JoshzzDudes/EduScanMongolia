# EduScan Mongolia

Багшид зориулсан шалгалт дүгнэх вэб апп. Хариултын хуудсаа хэвлээд, сурагчдын бөглөсөн хуудсыг утасны камераар уншуулж, дүнг автоматаар тооцоолно.

## Боломжууд

- **Хариултын хуудас.** 60 хүртэлх сонгох асуулт, 4 оронтой сурагчийн код, А/Б/В/Г хувилбар, задгай даалгаврын бүтэн текст болон шугамтай хариултын зай. Задгай даалгавар олон бол хуудасны ар талд (2-р нүүрт) хэвлэгдэнэ. Хуудсыг A4 PDF болгон татна.
- **Шууд скан.** Камерын дүрсэнд хуудсыг харуулахад дөрвөн булангийн хар дөрвөлжинг апп өөрөө олж, зургийг автоматаар авч уншина. Хоёр нүүртэй хуудсыг нэг нэгээр нь уншина. Код таарч, эргэлзээтэй хариулт байхгүй бол дүнг шууд хадгална.
- **Зургаар уншуулах.** Камерын апп-аар авсан эсвэл файлаас сонгосон зургийг мөн адил уншина.
- **Олон хуудас нэг дор.** Олон зураг, сканердсан PDF, эсвэл нэг зурагт 2–6 хуудас. Эргэлзээгүй хуудас өөрөө хадгалагдаж, бусдыг нь дараалан шалгана.
- **Хуудасны хоёр загвар.** Стандарт, камерт зориулсан (том дугуй, хажуугийн тэгшлэх тэмдэг, Times New Roman). Аль загвараар хэвлэснийг апп өөрөө таньна.
- **Анги, сурагч.** Excel/CSV-ээс импортлох, экспортлох.
- **Тайлан.** Дүнгийн тархалт, асуулт тус бүрийн шинжилгээ, Excel/CSV экспорт, сурагч бүрийн дүнгийн хуудас (PDF).

Шинэчлэлт бүрээр юу нэмэгдсэнийг [CHANGELOG.md](CHANGELOG.md) файлаас эсвэл апп доторх **«Шинэ боломжууд»** хэсгээс харна.

## Суулгах

1. Апп-ын хаягийг утасны **Chrome** (Android) эсвэл **Safari** (iPhone) хөтчөөр нээнэ.
2. Android дээр **«Апп болгон суулгах»** товч дээр дарна. Эсвэл Chrome-ийн ⋮ цэснээс **Add to Home screen**-ийг сонгоно.
3. iPhone дээр Safari-ийн **Share** товч → **Add to Home Screen**-ийг сонгоно.
4. Шууд сканыг анх эхлүүлэхэд камерын зөвшөөрөл асууна. **Allow (Зөвшөөрөх)** гэж дарна.

Нэг удаа нээсний дараа интернэтгүй үед ч ажиллана.

## Өгөгдөл

- Нэвтрээгүй үед бүх өгөгдөл (анги, сурагч, шалгалт, дүн) **зөвхөн тухайн төхөөрөмжийн хөтчид** хадгалагдана. Google-ээр нэвтэрвэл таны бүртгэлд хадгалагдаж синк хийгдэнэ.
- **Тохиргоо → Нөөц файл татах** товчоор өгөгдлөө тогтмол хадгална уу. Өөр төхөөрөмж рүү **Нөөцөөс сэргээх** товчоор шилжүүлнэ.
- Claude дахь EduScan-ийн өгөгдлийг мөн нөөц файлаар оруулж болно.
- Сурагчдын нэр бол хувийн мэдээлэл. Нөөц файлыг итгэлтэй газар хадгалж, бусдад бүү дамжуулаарай.

## Утас, компьютер хооронд синк хийх

Google бүртгэлээрээ нэвтэрвэл өгөгдөл Firebase үүлэн санд хадгалагдаж, утас, компьютер хооронд шууд синк хийгдэнэ. Утсан дээр уншуулсан дүн компьютерийн тайланд тэр даруй гарна. Интернэтгүй үед ч хадгалж, холбогдмогц илгээнэ. Тухайн төхөөрөмж дээр өмнө нь хадгалсан өгөгдөл анх нэвтрэхэд бүртгэл рүү автоматаар нэгтгэгдэнэ.

Тохируулах (нэг удаа):
1. Firebase төсөл үүсгэж, Authentication → Google нэвтрэлтийг асаана. Authorized domains-д сайтын хаягийг нэмнэ.
2. Firestore Database үүсгэж, `firestore.rules` файлын дүрмийг Rules хэсэгт оруулна.
3. Вэб апп бүртгэж, `firebaseConfig`-ийг `firebase-config.js` файлд оруулна.

Багш бүр зөвхөн өөрийн өгөгдлийг харж, засна (`users/{uid}/...`).

## Хөгжүүлэлт

- `src/eduscan.html`: апп-ын эх код. Claude дахь хувилбартай ижил файл.
- `build.py`: эх кодыг бие даасан вэб апп (`index.html`) болгон угсарна. `python3 build.py`
- `manifest.webmanifest`, `sw.js`, `icons/`: суулгах боломж болон интернэтгүй ажиллагаа.
- `cloud.js`, `firebase-config.js`, `firestore.rules`: Google нэвтрэлт ба синк.

Дараагийн шатууд: AI-аар задгай даалгавар үнэлэх серверийн функц (Claude API), Capacitor ашиглан Android/iOS апп болгох.
